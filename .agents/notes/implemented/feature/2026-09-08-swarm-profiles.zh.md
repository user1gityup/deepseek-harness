# Agent Note: 群组执行模式

Status: implemented

## Problem

仅按成本路由没有竞争产物或免费工作的付费验收。

## Decision

经济模式由免费席位竞争每单元，复用投票并付费审查，最多一个付费后备候选和两次付费审查。最快模式每单元一个付费工作者，独立波次并行。UI 单元优先合格已选作者。批准保留模式，预设不授权。

候选沿用沙箱，按运行、单元和席位隔离。经济模式要求验收条件，图拒绝共享目标文件。失败阻断依赖项。估算覆盖计划调用，不是金额硬上限。

## Alternatives considered

成本投票削弱计划。无审查不能证明有效节省。无限后备误导批准。共享目录可能覆盖文件。

## Consequences

经济模式需两个免费候选和付费审查。审查是模型判断，不运行测试。文件保持暂存。无模式保留旧行为。计划整合保留赢家，独立于代码选择。

## Verification

测试覆盖竞争、付费验收、有限失败、依赖阻断、隔离和最快路由。Loader 组合模拟外部回复执行真实工具并快照，无付费调用。
